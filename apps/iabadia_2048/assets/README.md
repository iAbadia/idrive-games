# Launcher icon

`icon.png` is the canonical 140×140 RGBA launcher image. The artwork fits
within 116×116 pixels with transparent 12px margins. Build and preview tools
copy this asset into the staged app and never redraw it.

Adapted from the user-supplied reference with the built-in image-generation
tool. Prompt: a warm golden rounded square, softly beveled amber rim,
raised cream-white numerals reading exactly 2048, restrained highlights;
straight-on square composition, transparent background, optimized for a
116px automotive launcher footprint. The large generated master stays
outside the repository; only the production PNG ships in the app package.
