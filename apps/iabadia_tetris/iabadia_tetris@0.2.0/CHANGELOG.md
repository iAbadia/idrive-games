# Changelog

## 0.2.0

- Require mgu-deploy 0.7.5+ for firmware-aware dual-platform service declarations.

- Dual ID7/ID8 resources and renderer host negotiation.
- ID8 direct FrontCCU fallback with the existing controller mapping.
- Local platform tests; ID8 vehicle validation remains pending.

## 0.1.1

- Use reference-based blue launcher artwork with transparent safe padding.

## 0.1.0

- Falling blocks with seven-bag randomization, three next pieces and ghost landing preview.
- Rotary movement, rotation kicks, soft/hard drop and bounded lock delay.
- Three starting speeds, increasing levels, saved progress and named best scores.
- Native pause menus and transparent padded launcher icon.
