# Changelog

## 0.2.0

- Require mgu-deploy 0.7.5+ for firmware-aware dual-platform service declarations.

- Dual ID7/ID8 resources and renderer host negotiation.
- ID8 direct FrontCCU fallback with the existing controller mapping.
- Local platform tests; ID8 vehicle validation remains pending.

## 0.1.1

- Reference-inspired launcher icon with transparent safe padding.
- Red apple food with a brown stem, green leaf and pixel highlights.

## 0.1.0

- Wheel-relative steering with buffered turns and three speed levels.
- OEM dark interface, native pause menus and safe restore on reopen.
- Saved progress and a named best score per speed.
